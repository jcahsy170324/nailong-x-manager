# Contributing

Thanks for contributing to NaiLong X Manager.

1. Open an issue describing the problem or proposed change.
2. Fork the repository and create a feature branch.
3. Keep changes dependency-free where possible and compatible with Chrome Manifest V3.
4. Test by loading the unpacked extension at `chrome://extensions` and checking the popup, dashboard, CSV export, and manual review workflow.
5. Submit a pull request with testing notes and screenshots (without personal account data).

Do not submit real follower lists, cookies, access tokens, or exported backups.
Do not add automatic mass-follow/unfollow or credential collection.
