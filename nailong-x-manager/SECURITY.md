# Security

This extension reads X follower/following list elements from the currently open page and stores collected records locally in Chrome extension storage.

- Never post your exported CSV or JSON backups publicly: they may contain your social graph.
- Do not enter X passwords or session cookies into this extension or GitHub issues.
- Review requested extension permissions before installing.
- Report potential vulnerabilities privately to the repository maintainer (configure a GitHub private vulnerability reporting channel when publishing).
- This is an unofficial community project, not affiliated with X.
